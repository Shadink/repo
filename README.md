## 🍃 Nook FM (acmusic)
<img width="1919" height="1028" alt="imagen" src="https://github.com/user-attachments/assets/b14e068c-e1d4-40ab-9881-4d09432ffc8a" />


### EN
An Animal Crossing Radio which plays songs according to local time and weather.
Installation and execution:
1. In your command line, go to "acmusic" folder
2. Execute command "npm start"
3. A tab will open on your browser and the corresponding song from the Animal Crossing OST will begin playing. The Animal Crossing version (game) can be changed to your preferred one using the buttons situated at the bottom of the video.
4. It's important (but not necessary) to allow autoplay and location access for a better experience.

Made using React.js and the [OpenWeather API](<https://openweathermap.org/api>). [Animal Crossing: Grass by rush57 on DeviantArt](<https://www.deviantart.com/rush57/art/Animal-Crossing-Grass-145470729>) was used as a background.

### ES
Una radio de canciones de Animal Crossing según la hora y el tiempo locales.
Instalación y ejecución:
1. En tu línea de comandos, entrar en la carpeta "acmusic"
2. Ejecutar el comando "npm start"
3. Se abrirá una página en el navegador y comenzará a sonar la canción correspondiente de la BSO de Animal Crossing. Se puede cambiar de versión (juego) de Animal Crossing al que se prefiera con los botones de debajo del vídeo.
4. Es importante (aunque no imprescindible) permitir autoplay y acceso a la ubicación para una mejor experiencia.

También accesible a través de [este link](https://nookfm.onrender.com/).
Creado utilizando React.js y la [API de OpenWeather](<https://openweathermap.org/api>). Utilizado como fondo [Animal Crossing: Grass de rush57 en DeviantArt](<https://www.deviantart.com/rush57/art/Animal-Crossing-Grass-145470729>)

## ✈️ Planificador de viajes
<img width="1280" height="685" alt="imagen" src="https://github.com/user-attachments/assets/07c8013e-06a1-4be0-b0fe-1d67e57763fd" />

### EN
A simple web app that provides comprehensive information for any travel destination. It includes categories such as Tourism, Leisure, Parks, Cafés, Bars, and Restaurants, with customization options for budget, number of activities, and distance from the accommodation.
Accesible via [this link](https://recomendador-de-viajes.streamlit.app/).
Made using Streamlit, Python and the Google Maps API.

### ES
Una web app sencilla de usar y con información exhaustiva para cualquier destino al que se quiera viajar, incluyendo lugares de Turismo, Ocio, Parques, Cafeterías, Bares y Restaurantes, con personalización tanto de presupuesto como de cantidad de actividades y distancia que se desea recorrer desde el lugar de alojamiento.
Accesible a través de [este link](https://recomendador-de-viajes.streamlit.app/).
Creado utilizando Streamlit, Python y la API de Google Maps.
